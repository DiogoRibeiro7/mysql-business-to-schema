# Node.js/TypeScript SDK

This folder contains the Node.js/TypeScript SDK for the MySQL Business-to-Schema project.

## Contents

- `package.json` with SDK metadata and scripts
- `src/` implementation and type definitions

## Quick Start

```bash
npm install
npm run build
```
