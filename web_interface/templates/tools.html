Usage Examples

Test Runner

Run comprehensive tests on all examples:

cd tools
python test_runner.py

# Test specific example
python test_runner.py --example example_10_fintech

# Generate detailed report
python test_runner.py --report html --output test_report.html
Schema Validator

Validate database schemas against best practices:

cd tools
python schema_validator.py ../example_11_social_media/schema/

# Check all schemas
python schema_validator.py --all

# Generate validation report
python schema_validator.py --report --output validation.json
Query Performance Analyzer

Analyze and optimize query performance:

cd tools
python query_analyzer.py ../example_12_real_estate/queries/

# Connect to live database
python query_analyzer.py --host localhost --user root --password

# Compare performance across examples
python query_analyzer.py --compare --examples 10,11,12

CI/CD Integration

GitHub Actions

Automated testing with GitHub Actions workflow:

name: Test Database Examples

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest

    services:
      mysql:
        image: mysql:8.0
        env:
          MYSQL_ROOT_PASSWORD: root
        options: >-
          --health-cmd="mysqladmin ping"
          --health-interval=10s
          --health-timeout=5s
          --health-retries=5

    steps:
    - uses: actions/checkout@v3

    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.9'

    - name: Install dependencies
      run: |
        poetry install --no-root --with web

    - name: Run tests
      run: |
        cd tools
        python test_runner.py --ci-mode

    - name: Validate schemas
      run: |
        cd tools
        python schema_validator.py --all --fail-on-warning

    - name: Upload results
      uses: actions/upload-artifact@v3
      with:
        name: test-results
        path: tools/test_results/
Docker Integration

Run tools in Docker container:

FROM python:3.9-slim

WORKDIR /app

COPY pyproject.toml poetry.lock* ./
RUN pip install --no-cache-dir poetry \
    && poetry config virtualenvs.create false \
    && poetry install --no-root --only main --with web --no-interaction --no-ansi

COPY tools/ ./tools/
COPY example*/ ./

CMD ["python", "tools/test_runner.py", "--all"]
