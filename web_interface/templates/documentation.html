Contributing

How to Contribute

We welcome contributions! Here's how you can help:

Adding a New Example
  1. Create a new directory following the pattern: example_XX_name
  2. Add required files:
    • README.md - Documentation
    • schema/01_tables.sql - Table definitions
    • queries/ - Example queries (optional)
    • data/ - Sample data (optional)
  3. Follow naming conventions and best practices
  4. Add tests in tools/tests/
  5. Update the main README
  6. Submit a pull request
Example Structure
example_14_your_domain/
├── README.md              # Documentation
├── schema/
│   ├── 00_create_database.sql
│   ├── 01_tables.sql
│   ├── 02_indexes.sql
│   └── 03_procedures.sql
├── queries/
│   ├── 01_basic.sql
│   └── 02_advanced.sql
├── data/
│   └── sample_data.sql
└── tests/
    └── test_schema.py
Code Standards
  • Use consistent SQL formatting
  • Follow MySQL 8.0 syntax
  • Include comments for complex logic
  • Provide realistic example data
  • Ensure all foreign keys are defined
  • Test with the validation tools
